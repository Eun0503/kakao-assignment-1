# 📝 React Weekly Todo Planner

바닐라 자바스크립트로 구현된 일간/주간 투두 플래너 애플리케이션을 **React 함수형 컴포넌트**와 **Tailwind CSS (v4)** 환경으로 마이그레이션한 프로젝트입니다.

---

## 🚀 주요 구현 기능

### 1. Todo CRUD & 인라인 수정
* **투두 등록**: 텍스트 입력 창과 버튼을 사용하여 새로운 투두 항목을 생성할 수 있습니다.
* **인라인 수정 모드**: `prompt()` 대신 리액트의 `isEditing` 상태에 따른 조건부 렌더링으로 인라인 수정창을 제공합니다.
  * **UX 최적화**: 수정창 전환 시 입력박스 자동 포커스 및 커서 맨 뒤 보정 기능이 탑재되어 있습니다.
  * **단축키 바인딩**: 수정창에서 `Enter` 입력 시 저장, `Escape` 입력 시 수정 취소가 가능합니다.
* **완료 토글 및 삭제**: 완료된 투두 항목은 취소선과 옅은 텍스트로 시각적으로 명확하게 구분됩니다.

### 2. 컴포넌트 독립 유효성 검사
* **공백 제출 방지**: 생성 및 수정 시 빈 입력이 제출되면 각각의 입력창 바로 하단에 빨간색 경고 메시지("할 일을 입력해주세요!")를 출력합니다.
* **경고 상태 해제**: 텍스트 상자에 입력을 다시 시작하면 경고 메시지가 즉시 사라져 좋은 사용자 경험을 제공합니다.

### 3. 상태별 필터링 기능
* **필터 3종**: 전체 / 진행 중 / 완료 탭을 제공하여 조건에 맞는 투두 목록을 보여줍니다.
* **필터 상태 관리**: 필터 상태는 `useState`로 관리되며, 탭을 전환한 후 새로운 투두를 추가해도 현재 필터 상태가 그대로 유지됩니다.

### 4. 일간/주간 뷰 및 투두 개수 트래킹
* **주간 날짜 목록**: 선택된 날짜가 속한 주간(월요일~일요일)의 날짜 카드 리스트를 노출합니다.
  * **오늘(Today) 강점 및 선택(Selected) 강점**: 오늘 날짜는 바이올렛 보더로, 선택된 날짜는 브랜드 시그니처 색상의 배경으로 구분됩니다.
* **요일별 투두 개수 배지**: 각 요일 카드 하단에 해당 일자에 등록된 총 투두 개수 배지가 실시간으로 표시됩니다.
* **주차 전환 네비게이션**: `<` 및 `>` 버튼으로 주차 단위 이동을 수행할 수 있습니다.

### 5. 로컬스토리지(localStorage) 데이터 연동
* **Lazy Initialization**: 컴포넌트가 처음 생성될 때만 로컬스토리지에 접근하도록 함수형 초기화를 설계하여 렌더링 성능을 개선했습니다.
* **자동 동기화**: `useEffect`를 사용해 투두 데이터, 선택 일자, 주간 노출 시작일이 변경될 때마다 JSON 포맷으로 저장소에 자동 갱신됩니다.
* **데이터 마이그레이션**: 과거 데이터에 `date` 정보가 유실된 경우 오늘 날짜로 자동 복구해 줍니다.

## 📂 프로젝트 파일 구조

```text
src/
├── components/
│   ├── TodoHeader.jsx       # 앱 헤더 타이틀 컴포넌트
│   ├── WeeklyNavigator.jsx  # 주간 달력 네비게이터 및 날짜 카드
│   ├── TodoForm.jsx         # 신규 투두 등록 입력 폼 (로컬 유효성 검사 탑재)
│   ├── TodoList.jsx         # 투두 목록 컨테이너 (필터별 Empty State 메시지 처리)
│   └── TodoItem.jsx         # 개별 투두 항목 (뷰 모드 / 인라인 수정 모드 전환)
├── utils/
│   └── date.js              # 날짜 포맷 및 주간 계산 유틸리티 헬퍼 함수
├── App.jsx                  # 최상위 상태(todos, dates, filters) 및 비즈니스 로직
├── App.css                  # 커스텀 컴포넌트 추가 스타일
├── index.css                # Tailwind CSS v4 연동 및 테마 설정
└── main.jsx                 # React DOM 진입점
```
